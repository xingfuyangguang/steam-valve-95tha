# 补汽阀 95% THA 开点 · 交互演示

单文件前端（约 10 KB，零外部依赖、零网络请求），拖动滑块即可看出力—热耗—阀位的联动。

- 在线访问：https://xingfuyangguang.github.io/steam-valve-95tha/
- 技术栈：HTML + CSS + 原生 Canvas 2D，无框架、无 CDN
- 数据口径：**示意曲线**。按 1000MW 级超超临界机组典型形态构造（补汽阀 95% THA 起开、105% 全开、补汽通路单位流量出力系数 0.85），热耗基准 7350 kJ/kWh，**非实测数据**，仅用于说明“出力—热耗”耦合关系。
- 换实测数据：改 `index.html` 里的 `M.power()` / `M.hr()` 两个函数即可，卡片数字与曲线会一起变。
