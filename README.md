# 补汽阀 95% THA 开点 · 交互演示

拖动负荷滑块，看 **出力 — 热耗 — 阀位** 三者如何联动。静态图只能给结论，这里可以自己试探边界。

- 在线访问：https://xingfuyangguang.github.io/steam-valve-95tha/
- 技术栈：HTML + CSS + 原生 Canvas 2D，无框架、无 CDN、无外部脚本
- 视频：24 s 动效讲解片，页面内嵌播放，媒体文件托管在发布站点（不入仓库，避免仓库体积膨胀）

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件交互演示（唯一入口） |
| `.nojekyll` | 关闭 Jekyll 处理，静态直出 |

## 页面结构

1. 上：发电功率曲线（MW vs 负荷 %）
2. 下：热耗率曲线（kJ/kWh vs 负荷 %），95% 前后分段着色
3. 右：功率 / 热耗 / 阀位三张卡片 + 阀位扇形表
4. 底：动效版视频 + 随滑块位置变化的机理判语

## 数据口径

示意曲线，非实测数据。按 1000 MW 级超超临界机组典型形态构造：补汽阀 95% THA 起开、105% 全开，补汽通路单位流量出力系数 0.85，热耗基准 7350 kJ/kWh。仅用于说明「用热耗换出力」的耦合关系，不作选型或性能保证依据。

改数据只需动 `index.html` 里 `M.power()` 与 `M.hr()` 两个函数，卡片数字与曲线同步变化。
